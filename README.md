# AnimClips

  AnimClips एक एनिमेशन विडियोज की एक विशाल लाइब्रेरी है,जहाँ पर फ्री में छोटे छोटे Video Clips  HD, SD में डाउनलोड कर सकते हैं
- **श्रेणी आधारित ब्राउज़िंग**: विभिन्न एनिमेशन श्रेणियों (3D, 2D, मोशन ग्राफिक्स आदि) से ढूंढें
- **फीचर्ड, लोकप्रिय और हाल के वीडियो**: विभिन्न प्रकार के वीडियो कलेक्शन
- **वीडियो स्ट्रीमिंग**: वीडियो प्रीव्यू के लिए इनलाइन प्लेयर
- **उत्तरदायी डिज़ाइन**: मोबाइल, टैबलेट और डेस्कटॉप पर अच्छी दिखने वाली वेबसाइट

## तकनीकी स्टैक

- **फ्रंटएंड**: React, TailwindCSS, Shadcn/UI
- **बैकएंड**: Express.js
- **वीडियो प्रोसेसिंग**: FFmpeg
- **स्टोरेज**: इन-मेमोरी (विकास के लिए) / डेटाबेस ऑप्शनल

## स्थापना और शुरुआत

```bash
# प्रोजेक्ट क्लोन करें
git clone https://github.com/yourusername/animclips.git
cd animclips

# निर्भरताएँ इंस्टॉल करें
npm install

# अपलोड फ़ोल्डर बनाएँ
mkdir -p uploads/videos uploads/thumbnails

# FFmpeg इंस्टॉल करें (यदि पहले से इंस्टॉल नहीं है)
# आपके ऑपरेटिंग सिस्टम के लिए उपयुक्त निर्देशों का पालन करें

# विकास सर्वर शुरू करें
npm run dev
```

सर्वर `http://localhost:5000` पर चलेगा
